# Análisis característico de los Usuarios de Netflix
Este proyecto busca analizar las características y preferencias de los usuarios de la plataforma en función a factores como edad y ubicación geográfica

## Interrogante principal
¿Cuáles son las características de los usuarios actuales de Netflix en relación con su tipo de suscripción, género favorito y método de pago?

## Objetivos específicos
- Conocer qué tipo de suscripción es la mas frecuente entre los usuarios activos
- Buscar cual es el genero mas visto en cada region por rango etario.
- Detectar cuál es el metodo de pago mas elegido de cada region.

## Data Set utilizado
En esta oportunidad se obtuvo el archivo inicial a través de la plataforma de Kaggle, el mismo contiene 5000 filas y 14 columnas.
Cada registro corresponde a un usuario registrado en la plataforma e incluye informacion sobre:
- Edad del usuario
- Género del usuario.
- Tipo de suscripción del usuario
- Horas de visualización de contenido
- Días desde la última conexión
- Región geográfica
- Dispositivo utilizado
- Monto mensual de la suscripción
- Estado del usuario
- Método de pago utilizado
- Cantidad de perfiles utilizados por el usuario
- Promedio de tiempo de visualización por día
- Género favorito

## Tecnologías y librerías
Herramientas utilizadas:
- Python 2.2.3
- Pandas
- Numpy
- Matplotlib
- Seaborn
- Power Bi

## Resultados 
1. Suscripción mas elegida:
   
La suscripción Basic es la más frecuente entre los usuarios activos, con 1.027 usuarios, mientras que Standard y Premium presentan cantidades similares, con 748 y 740 usuarios respectivamente.

2. Género favorito por región y rango etario:
   
Drama aparece como género predominante entre los usuarios mas jóvenes en África, Europa y Oceanía, mientras que en Norteamérica y Sudamérica predomina Romance para este grupo. En los usuarios de mayor edad, se observan diferentes preferencias según la región sin un género predominante.

Los métodos de pago mas elegidos en todas las regiones son Crypto y Gift Card.
